# Statistics

Statistics provides the framework for drawing reliable conclusions from biological data.

Understanding statistics makes it possible to distinguish meaningful biological signals from random variation.

## Topics

### Descriptive Statistics

- Mean
- Median
- Standard Deviation
- Variance

### Inferential Statistics

- Hypothesis Testing
- Confidence Intervals
- P-values

### Common Tests

- T-tests
- ANOVA
- Correlation
- Regression

## Biological Applications

- Experimental analysis
- Cell biology
- Immunology
- Transcriptomics
- Therapeutic development

## Goal

Develop the ability to critically evaluate biological experiments and data.
