# Mathematics

Mathematics is the language used to describe, model, and predict biological systems.

As biology becomes increasingly quantitative, mathematical understanding becomes essential for interpreting data, building models, and understanding machine learning algorithms.

## Areas of Study

### Calculus

Topics:

- Limits
- Derivatives
- Integrals
- Differential Equations

Applications:

- Population growth
- Biological dynamics
- Systems biology

### Linear Algebra

Topics:

- Vectors
- Matrices
- Matrix Multiplication
- Eigenvalues
- Eigenvectors

Applications:

- PCA
- Machine Learning
- Data Transformation

### Probability

Topics:

- Probability distributions
- Random variables
- Bayesian reasoning

Applications:

- Experimental design
- Statistical inference

## Goal

Develop intuition for the mathematical foundations of computational biology and machine learning.
