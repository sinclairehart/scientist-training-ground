# Scientist Training Ground

Welcome to my scientific learning repository.

This repository documents my transition from experimental biology toward quantitative biology, computational biology, systems biology, machine learning, and predictive biology.

Rather than simply collecting code, the goal of this repository is to build a deep understanding of the mathematics, programming, biological concepts, and analytical methods that underpin modern biological research.

## Repository Philosophy

The goal is not only to learn how to use tools.

The goal is to understand:

- Why methods work
- When methods fail
- Biological interpretation
- Mathematical foundations
- Practical implementation

Each topic contains:

- Concepts
- Notes
- Explanations
- Example code
- Exercises
- Biological applications

## Areas of Study

### Programming

Learning Python for scientific computing, automation, data analysis, machine learning, and bioinformatics.

### Mathematics

Developing mathematical intuition needed for statistics, machine learning, systems biology, and computational modeling.

### Statistics

Learning how biological conclusions are derived from experimental data.

### Machine Learning

Developing an understanding of dimensionality reduction, clustering, classification, validation, and predictive modeling.

### Computational Biology

Applying computational tools to biological systems including transcriptomics, immunology, systems biology, and bioinformatics.

### Scientific Communication

Developing the ability to communicate scientific findings clearly and effectively.

Build the skills necessary to understand, predict, and engineer biological systems through the integration of biology, mathematics, computation, and machine learning.
